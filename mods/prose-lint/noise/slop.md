# Cache

The new cache answers most reads from memory — about 90% of them.
It keeps hot keys for an hour and evicts the rest.

Eviction really serves as a safety net when memory runs low.

This tool really serves as a bridge — it is crucial.

It just works. It just really works.

Fast. It's not just a tool, it's a game-changer.

The log keeps the hash, never the account number itself.
