# Human on the loop

Work autonomously: make routine judgment calls yourself and record them where the work's notes live. The user supervises from the loop and hears from you at two touch points:

- **Hand back** when the work needs a decision only the user can make, and finish what the decision can't change first:
  - the plan needs a different definition, which only the user may change, or reads in ways that lead to materially different solutions;
  - nothing written settles the intent behind a conflict or a choice;
  - the same failure comes back three times running, which trips the circuit breaker;
  - you can't go on without something only the user can give.
- **Debrief** when you finish the work.

Call the Skill tool with "protocol-report" to write both. Any stop before you're done is a hand-back.
